# 仓库隐私说明

检查日期：2026-10-10。此仓库公开应用源码、构建配置、依赖许可、合成或公开来源的测试夹具、版本说明及 `release-assets` 中的正式 APK。

签名私钥与口令、本地工具链、构建缓存、详细测试日志、截图、交接文档、对话记录以及 `delivery` 中的本地验收资料均由 `.gitignore` 排除。正式 APK 的签名证书和校验值是公开验证材料，签名私钥不包含在 APK 内。

本轮检查覆盖当前可提交文件、12 个本地可达提交及其 83 个历史文件对象，并检查已归档 APK 的解压内容。没有检出常见访问令牌、私钥标记、本地签名口令、个人 Windows 用户目录或微信账号标识。此结果描述本轮检查范围，不是对所有形式敏感信息的绝对保证。

Git 提交的作者与提交者身份也是公开元数据。检查时发现 4 个本地历史提交使用了非 GitHub noreply 邮箱；经仓库所有者确认，尚未推送的 1.6.1 提交已匿名化，并验证源码树完全一致。后续本仓库提交使用已有的 GitHub noreply 身份。剩余 3 个提交属于已经公开的历史，仍保留原身份元数据；处理公开历史需要单独评估，不能通过普通新增提交消除。

合成 Word 测试夹具已移除作者和最后修改者字段。Apache POI 测试夹具来自公开项目，其来源和许可见 `app/src/androidTest/assets/README.txt`。发布 APK 不包含这些测试夹具，也不包含开发者或用户的阅读文件、阅读历史和批注草稿。

应用不申请网络或全部文件访问权限，文档访问通过 Android 文件授权；应用内阅读记录、导入副本、草稿和批注保存在本机。用户主动另存或分享文档时，保存结果可能包含原文档自身的作者元数据以及用户添加的批注，应按文档内容决定分享范围。
