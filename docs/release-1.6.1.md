# 纸阅 1.6.1

日期：2026-10-10。包名 `cn.paperpdf.reader`，versionCode 8；沿用原发布签名，可覆盖安装 1.6.0。

[安装包](../release-assets/PaperPDF-1.6.1.apk) · 11,967,754 bytes · SHA-256：`3279582A1473F91E2D96D0EE57C8237BB07C3A87365A0899FF4D20AD5DFD637F`

修复约 600 MB PDF 打开时的内存不足。PDF 无固定文件大小上限；此前 PDFBox 默认无限内存数据流缓存造成内存耗尽，本版为打开/解密、搜索和导出的每个文档配置 8 MiB 流缓存预算，超出部分写入私有磁盘临时文件，正常关闭后删除。

34 项 Android 11 专用模拟器集成测试通过，含一个 600 MiB 有效 PDF 数据流的实际打开、显示、翻页、搜索和导出。旧版同夹具触发 OutOfMemoryError，新版通过。release 构建、lint、签名及 1.6.0 → 1.6.1 覆盖升级/冷启动通过。代码审查的翻页等待断言已补强。

未取得用户原始 600 MB PDF 或用户实体手机验证。流缓存预算不是整个应用的内存上限；庞大对象树、单页复杂图像解码仍可能受到设备内存限制，大文件的工作副本和临时文件需要足够本地存储。Word 的 64 MB 保护上限及兼容排版边界沿用 1.6.0。

本页提供公开验证摘要。详细测试日志、截图和本地验收材料保留在开发环境，不随源码仓库上传。安装包可通过本页及仓库 README 的相对链接下载。
